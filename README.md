#  PetSphere

A full-stack MERN application for **pet adoption and pet product
management**, designed to create a seamless experience for users looking
to adopt pets or explore pet-related products.

------------------------------------------------------------------------

##  Motivation

Finding pets for adoption and accessing reliable pet products often
requires switching between multiple platforms.

The goal of this project was to build a **unified system** that:

-   Simplifies pet adoption
-   Provides a centralized pet product marketplace
-   Ensures secure user authentication
-   Delivers a smooth full-stack experience

------------------------------------------------------------------------

##  Features

###  Pet Adoption System

-   Browse available pets
-   View detailed pet information
-   Adopt pets through a simple interface

###  Pet Products Module

-   Explore pet-related products
-   View product details and pricing

###  Authentication System

-   User registration & login
-   Secure password handling
-   JWT-based authentication
-   Protected routes

###  User Management

-   Profile access
-   Personalized experience

------------------------------------------------------------------------

##  Setup Instructions

### 1. Clone Repository

```
git clone https://github.com/mirdulaabalaji/mernproject.git 
cd mernproject-main
```

### 2. Backend Setup

```
cd backend
npm install
```

Create a `.env` file:

```
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
PORT=5000
```

Run backend:

```
npm start
```

### 3. Frontend Setup

```
cd ../frontend
npm install
npm start
```
